

2026-2학기 교사별 시간표 (임시).pdf
PDF
첨부한 교사시간표에 따라 교사의 시간표를 조회하고 2명 이상의 교사를 선택하면 공강시간을 비교해서 보여주는 스트림릿 클라우드에서 동작하는 웹앱을 만들어줘

첨부한 「2026-2학기 교사별 시간표(임시)」 72페이지 전체를 기준으로 72명 교사의 시간표를 추출해서 Streamlit Cloud용 웹앱으로 만들었습니다. PDF는 교사별로 주간 시간표가 구성되어 있고, 예를 들어 강민영 교사는 주 15시간으로 월~금 1~7교시 수업이 배치되어 있습니다. 


앱에서는 교사 1명을 선택하면 개인 시간표와 공강을 표시하고, 2명 이상을 선택하면 선택한 모든 교사가 동시에 비어 있는 공통 공강을 자동으로 계산합니다. 3명, 4명처럼 여러 명도 동시에 비교할 수 있으며, 공통 공강은 요일·교시 목록과 주간표로 표시되고 CSV 다운로드도 가능합니다.

바로 사용할 수 있도록 app.py, teacher_timetable.json, requirements.txt, 배포 안내 README.md를 묶었습니다.

Streamlit Cloud에 올리는 방법
압축을 풀어 나온 아래 3개 파일을 GitHub 저장소의 같은 위치(루트)에 올리면 됩니다.

app.py
teacher_timetable.json
requirements.txt
그다음 Streamlit Community Cloud에서 GitHub 저장소를 연결하고 **Main file path를 app.py**로 지정하여 Deploy 하면 됩니다.

이번에는 PDF를 앱에서 매번 읽도록 하지 않고, 시간표를 미리 JSON으로 변환해 두었습니다. 그래서 Streamlit Cloud에서 실행 속도가 빠르고 pdfplumber 같은 PDF 라이브러리도 필요하지 않습니다.

또한 추출 과정에서 PDF에 적힌 각 교사의 총 수업시간과 실제 추출된 수업 교시 수를 72명 전부 대조했고 모두 일치하도록 확인했습니다.

원하시면 다음 단계로 이 앱을 더 학교용답게 바꿔서 ① 교사 이름 검색창, ② 2명 공강 비교를 더 크게 표시, ③ 특정 요일·교시에서 공강인 모든 교사 찾기, ④ “지금 공강인 교사” 찾기, ⑤ 모바일 화면 최적화까지 추가해드릴 수 있습니다.




1개 더 보기

그냥 pdf를 앱에서 업로드 할 수있는 기능을 넣어서 만들어주고 처음에는 깃허브에 있는 pdf를 이용해서 만들도록 코드를수정해줘

수정했습니다. 이제 JSON 파일 없이 PDF 자체를 읽어서 시간표를 만드는 방식입니다. 첨부된 PDF처럼 교사별로 1페이지씩 시간표가 있고, 월~금 1~7교시 표로 구성된 형식을 기준으로 분석하도록 만들었습니다. 첨부 PDF도 실제로 이 구조로 구성되어 있습니다. 


처음 앱을 실행하면 GitHub 저장소에 있는 기본 PDF를 자동으로 읽습니다. Streamlit Cloud에서는 GitHub 저장소의 파일이 그대로 배포되므로 app.py와 같은 위치에 다음 PDF를 두면 됩니다.

2026-2학기 교사별 시간표 (임시).pdf
그리고 앱 왼쪽 사이드바에 「새 시간표 PDF 업로드」 기능을 추가했습니다. 새 학기 시간표 PDF를 업로드하면 GitHub의 기본 PDF 대신 업로드한 PDF를 즉시 분석해서 교사 목록과 시간표를 새로 만듭니다.

첨부하신 현재 PDF로 테스트했을 때 72명 교사 전체가 정상 인식되었고, 각 페이지에 적힌 총 수업시간과 추출된 실제 수업 교시 수도 72명 모두 일치했습니다.

동작 방식
앱을 처음 열었을 때는

GitHub PDF → PDF 분석 → 72명 교사 시간표 생성 → 교사 선택

순서로 동작합니다.

이후 왼쪽에서 새 PDF를 업로드하면

업로드 PDF → 자동 재분석 → 교사목록 변경 → 공강 비교

로 바뀝니다.

따라서 다음 학기에 시간표가 바뀌어도 코드를 수정하거나 JSON을 다시 만들 필요가 없습니다. 새 PDF만 업로드하면 됩니다.

현재 앱은 그대로 교사 1명 선택 → 개인 시간표/공강 조회, 2명 이상 선택 → 공통 공강 자동 계산, 3명·4명 이상도 공통 공강 계산, 공통 공강 CSV 다운로드까지 지원합니다.
